# HOME / SECURE 华为云本地联调

本项目只用于电脑端微信开发者工具联调，不包含后端服务。小程序会直接调用华为云 IoTDA 的 HTTPS API：

- 读取设备影子：`GET /v5/iot/{project_id}/devices/{device_id}/shadow`
- 下发门锁命令：`POST /v5/iot/{project_id}/devices/{device_id}/commands`

## 只需要填写 4 个值

打开 `utils/huaweiCloud.js`，填写文件顶部的 `CLOUD_CONFIG`：

```js
endpoint: 'https://iotda.<你的区域>.myhuaweicloud.com',
projectId: '你的 IAM 项目 ID',
deviceId: 'AI 智能门锁的设备 ID',
token: '你的临时 X-Subject-Token',
```

### 1. endpoint

在华为云 IoTDA 实例的“总览/接入信息”中复制应用侧 API 接入地址。不要填写控制台网页地址。

### 2. projectId

进入“我的凭证 → API 凭证 → 项目列表”，复制与 IoTDA 实例相同区域的项目 ID。

### 3. deviceId

进入“IoTDA → 设备 → 所有设备”，打开名为“AI 智能门锁”的设备详情，复制设备 ID。

注意：截图里的 `6ae2ec55e094d615927e08d0` 是产品 ID，不是设备 ID。

### 4. token

获取 IAM 认证返回的临时 `X-Subject-Token`。Token 会过期，失效后重新获取并替换。

## 已按产品模型配置好

```js
environmentServiceId: 'id1',
temperatureProperty: 'temp',
lockServiceId: 'id1',
lockProperty: 'lock_state',
lockedValue: true,
commands: {
	unlock: { name: 'set_lock_state', paras: { lock_state: false } },
	lock: { name: 'set_lock_state', paras: { lock_state: true } }
}
```

## 本地运行

1. 用 HBuilderX 打开项目，运行到微信开发者工具。
2. 微信开发者工具中进入“详情 → 本地设置”，勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
3. 打开首页后点击“刷新”，观察控制台中的 `[IoTDA shadow]` 数据和页面温度、锁状态。
4. 点击开锁/上锁，云端会向设备下发 `set_lock_state` 命令。

## 说明

- 设备必须在线，并且设备端已经实现 `set_lock_state` 命令，门锁才会实际动作。
- 当前方式仅适合个人电脑上的短期联调。临时 IAM Token 也不能提交到公开仓库或用于正式发布。
- 页面固定显示 `°C`，请确认设备的 `temp` 属性上报的是摄氏度。
